## Sobre
Este é um simples projeto em HTML e CSS simulando um card com QRcode para leitura, links externos, imagens e texto. Feito para fins de aprendizado e prática em estruturação e estilização de páginas web. Além de técnicas de estilização como display-flex e responsividade
